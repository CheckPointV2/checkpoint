**2. Bed type: please always check it**
The twin room types were removed, so **DBA, KGA and KGAOV now include both king and twin rooms**. The bed type is shown clearly:
- a **KING** or **TWIN** badge on every DBA / KGA / KGAOV room on the floor plan
- a **Bed type** card in the room details (e.g. "Superior Room · Twin beds")
- a new **Bed** filter (King / Twin), e.g. to find all twin Superior rooms

**3. Interconnecting rooms**
- Only **18 pairs** are now configured in the system as interconnecting:
  - **D3A**, 4 pairs: 1151/1152, 2355/2356, 2459/2460, 2536/2537
  - **D3B**, 9 pairs: 1421/1422, 1427/1428, 1439/1440, 1445/1446, 2157/2158, 2463/2464, 2549/2550, 2555/2556, 2563/2564
  - **D3C**, 5 pairs: 1402/1403, 1409/1410, 1415/1416, 1433/1434, 2557/2558
- On the floor plan:
  - **Solid gold ring:** an interconnecting pair configured in the system.
  - **Dashed ring (PHY):** the rooms have a connecting door but are **not configured as interconnecting**. Please **do not sell these as interconnecting**.

**4. Faster daily work**
- **Search** by room number or by words, e.g. "superior twin", "D3B", "PHY". Each result shows the bed type and the connecting room (e.g. "Inter 2158 · D3B").
- **Copy for Opera:** after filtering, one click copies the room list in Opera format (e.g. 2003,2005,2054), ready to paste.
- **3D tours:** a "View 3D tour" button under the room photo.

**5. Old / New switch**
The guide opens on **New** (today's room types). Use the **Old | New** switch at the top to see the previous room types at any time.

**6. Quick tour**
A short tour opens the first time you log in after this update. You can replay it any time with the **?** button.
